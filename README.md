# YouTube Playlist Downloader

Скрипт для загрузки видео из одного или нескольких плейлистов YouTube в указанную директорию.

---

## 📌 Описание

Этот скрипт позволяет:
- Скачивать все видео из указанных плейлистов YouTube.
- Сохранять видео в отдельных папках для каждого плейлиста.
- Обрабатывать ошибки (например, недоступные видео или плейлисты).
- Использовать безопасные названия папок (удаление недопустимых символов).
- Загружать видео в формате MP4 с наивысшим доступным разрешением.

---

## 📦 Установка

Установите зависимости:

```bash
pip install pytubefix
```

или

```
uv venv && uv sync --frozen --no-cache
```
